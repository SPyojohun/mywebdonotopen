nnn reward - how to use
1. Open index.html in a browser to try it (data saves in IndexedDB on that device/browser).
2. To install as an app and use offline, put ALL files in this folder (same level, no sub-folders) on an HTTPS host such as GitHub Pages:
   index.html, app.js, style.css, theme.js, qr.js, sw.js, manifest.json, icon-192.png, icon-512.png, maskable-512.png
3. Open the site in Chrome (Android) or Safari (iPhone). Press Install in the header for a checklist and the exact steps.
4. Data lives per device. Use Share (file or link) or Export/Import backup to move it between devices.
5. After updating, upload ALL files together (a mix of old and new files breaks parts of the app). If the app shows a red 'files are out of date' bar, upload everything again and press the button.

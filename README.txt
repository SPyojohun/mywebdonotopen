nnn reward - how to use
1. Open index.html in a browser to try it (data saves in IndexedDB on that device/browser).
2. For PWA install + offline, host the folder on HTTPS (GitHub Pages, Netlify, Cloudflare Pages) then use "Install app" / "Add to Home Screen".
3. Data lives per device. Use Links > Export backup / Import backup to move it between devices.
